# União Transportes — Consulta de Filiais

Aplicação web instalável (PWA), otimizada para Android, para consultar qual filial atende uma cidade.

## Recursos
- Busca por cidade ignorando diferenças de maiúsculas e acentos.
- Até três sugestões, exclusivamente entre cidades cadastradas.
- Cadastro, edição e exclusão de filiais e cidades.
- Dados salvos no armazenamento local do dispositivo.
- Interface responsiva com identidade visual azul-marinho.
- Funcionamento offline após a primeira visita, em hospedagem HTTPS.

## Publicar
Ative Settings → Pages → Deploy from a branch → main → /(root) para publicar como GitHub Pages.

## Instalar no Android
Abra o endereço publicado no Chrome Android e use o menu → Instalar app ou Adicionar à tela inicial.

## Dados
Os cadastros ficam no navegador/dispositivo e não sincronizam automaticamente entre aparelhos. Faça backup antes de limpar os dados do navegador.

## Imagem de fundo
O aplicativo está configurado para usar assets/uniao-fundo.jpg como fundo. A imagem de referência precisa ser enviada para essa pasta no repositório.
